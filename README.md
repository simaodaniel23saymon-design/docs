# NZOChain Docs

Documentação Mintlify publicada em [docs.nzochain.com](https://docs.nzochain.com).

Fonte de verdade do produto: app B2C, portal B2B e API (`nzochain-api`). Este repositório descreve o que está **em produção** (preços, 4 chains, API v1, gating).

```bash
npm i -g mint
mint dev
```

Push para `main` dispara o deploy Mintlify ligado a este GitHub.
