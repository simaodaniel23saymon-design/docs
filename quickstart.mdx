## B2C — proteger a tua wallet

1. Abre [app.nzochain.com](https://app.nzochain.com).
2. Liga a carteira e **assina uma mensagem**. É prova de posse — **não move fundos**.
3. A NZOChain analisa aprovações, contratos e ligações nas **4 redes** suportadas.
4. Vês o nível de risco (Safe / Warning / High Risk / Critical) e o que está activo.
5. Para revogar, confirmas a transacção **na tua carteira**.

<Warning>
Se alguém a fingir ser a NZOChain pedir seed ou chave privada, é phishing. Nós nunca pedimos isso.
</Warning>

Planos: [Free → Premium](/pricing/individual). O Free chega para 1 wallet.

## B2B — integrar a API

1. Cria conta em [developers.nzochain.com](https://developers.nzochain.com).
2. Cria um projecto e uma API key (`pk_live_...`).
3. Envia `X-API-Key` em `https://api.nzochain.com/api/...`.
4. Wallet/contract risk está no **Free**. `analyze` / `simulate` exigem **Starter+**. Threat intel exige **Growth+**.

Detalhe: [Autenticação](/api/authentication) e [API v1](/api/v1).

## Exemplo mínimo (v1)

```bash
curl -X POST "https://api.nzochain.com/api/v1/wallets/risk?lang=en" \
  -H "Content-Type: application/json" \
  -H "X-API-Key: pk_live_SUA_CHAVE" \
  -d '{"wallet":"0x...","network":"ethereum"}'
```

Resposta normalizada: `riskLevel`, `decision` (`ALLOW | REVIEW | BLOCK`), `reasons` em linguagem humana.
